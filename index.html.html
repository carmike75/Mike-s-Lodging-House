Project
First-time setup (one time only)
1. Go to supabase.com, sign in, and create a free project (or reuse your existing one).
2. Open Project Settings → API. Copy the Project URL and the anon public key into the boxes above.
3. Open SQL Editor, paste the block below, and press Run to create the storage table: 
create table if not exists lodging_state (
  id text primary key,
  data jsonb not null,
  updated_at timestamptz default now()
);
alter table lodging_state enable row level security;
create policy "anon all" on lodging_state
  for all to anon using (true) with check (true);
4. Press Connect. On your first device it uploads your data; on the next device it pulls it down.
Note: the anon key is safe to embed, but anyone with your URL + key could reach this data, so keep them private. The app's PIN protects the screen, not the database.
